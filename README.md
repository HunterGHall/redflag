## Description: 
redflag is a lightweight local tool for analyzing conversations and transcripts to detect suspicious or predatory behavior. It is designed to help flag patterns that may indicate grooming, manipulation, or predatory intent so users can review risky interactions more quickly.

## Setup

1. Install the required model files:
   python src/models/get_models.py

2. Update the transcript path in main.py if needed.

3. Run the app:
   python main.py
